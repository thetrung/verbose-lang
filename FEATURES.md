# VerBose-Lang — Implemented Features

VerBose-Lang is a brace-free, VB6/VB.NET-inspired systems programming language compiled directly to LLVM IR without a garbage collector.

## Language & Runtime Features

- **Types, Strings & Expressions**: `Byte`, `Short`, `Integer`, `Long`, `Single`, `Double`, `Boolean`, `Pointer`, `String` (type alias for `Pointer`), `Nothing`, built-in explicit scalar/pointer type conversions (`Byte(x)`, `Short(x)`, `Integer(x)`, `Long(x)`, `Single(x)`, `Double(x)`, `Boolean(x)`, `Pointer(x)`, `String(x)`), 64-bit decimal & hex integer literals (`0x...`, automatic `Long` promotion for values `> 2^31 - 1`), scientific notation float literals (`1.0e-4`, `1e5`, `1.7976931348623157e308`), IEEE-754 unordered float `<>` (`fcmp une` so `NaN <> NaN` is `True`), unary negation (`-x`), contextual literal typing, arithmetic/comparison/logical/bitwise operators (`+`, `-`, `*`, `/`, `Mod`, `=`, `<>`, `<`, `>`, `<=`, `>=`, short-circuiting boolean & bitwise integer `And`/`Or`, `Xor`, `Not`, `Shl`, `Shr`), rvalue member access and chained rvalue indexing (`MakeShip().tf.pos.x`, `MakeLabel()(0)`, `(Await job).field`), multi-line function/struct-constructor call arguments, native string concatenation (`&` and `+` on `Pointer`/`Byte` arrays with compile-time folding, multiline `&` continuations, and lazy runtime `@__vb_str_concat`), and VB.NET-style string interpolation (`$"..."` with `{expr}`, `{{`/`}}` escaping, nested interpolation, constant folding, and exact-size lowering).
- **Grouped Declarations**: Same-type and mixed-type comma-separated declarations across `Dim`, `Static`, `Public Static`, `Private Static`, `Structure` fields, and `Function`/`Sub`/`Declare` parameters (e.g. `Dim a, b, c As Integer = 0`, `Dim x = 1, y = 2 As Integer`, `Sub Swap(ByRef a, b As Integer)`).
- **Control Flow, Pattern Matching & Deterministic Cleanup (`Defer`)**: `If / Then / Else / End If`, enforced `While ... Do / End While` and `For ... To ... Do / End For`, `Break` and `Continue` loop control statements (validated inside loops by the Type Analyzer, targeting the innermost `While`/`For` loop with proper `For` counter increment on `Continue`), lexical-scope `Defer <stmt>` and `Defer ... End Defer` blocks (executing in LIFO order on normal block exit, `Return`, `Break`, `Continue`, and outward `GoTo`, evaluating `Return` expressions before running deferred cleanup, and rejecting escaping `Return`/`Break`/`Continue`/`GoTo`/`Label` or `GoTo` crossing a `Defer` at compile time), OCaml/VB-style `Match [expr] With / Case ... [When <guard>] Then / Case _ / End Match` (single-line & multi-line arms, comma-separated multi-value patterns, tagged `Union` variant destructuring with scoped payload bindings and compile-time exhaustiveness checking, conditional ladders, and null-safe string matching via `@__vb_str_eq`), backwards-compatible `Select Case ... End Select` (desugared into `Match`), zero-copy `With <lvalue> ... End With` member-access blocks, plus function-scoped `Label <name>` and `GoTo <name>` with compile-time label validation.
- **Generics (Monomorphized Parametric Types & Routines)**: Brace-free VB.NET-style `(Of T, ...)` type parameters on `Structure`, `Union`, `Function`/`Sub` (including `Async`), and `Operator` overloads with zero-overhead compile-time monomorphization (`src/generics.vb`, no boxing, no runtime dispatch). Supports nested generic types (`Box(Of Pair(Of A, B))`, `Option(Of Result(Of T, E))`, `Task(Box(Of T))`), explicit `(Of ...)` and structural call-site type argument inference (for functions, subs, struct constructors/`With` initializers, and generic operators), `T(x)` primitive cast/constructor rewriting, `SizeOf(T)`/`ArenaAlloc`/`HeapAlloc`/`PtrRead`/`PtrWrite`, `AddressOf(Fn(Of T))`, recursion/depth guards, and cross-module `Private` isolation.
- **Tagged Unions / Sum Types (`Union`)**: Zero-GC inline tagged algebraic data types (`[Public|Private] Union Name[(Of T, ...)] ... Case Variant[(fields)] ... End Union`) lowered to alignment-safe `%union.<Name> = type { i32 [, [N x i{8|16|32|64}]] }` across all 64-bit targets and bare-metal `arm-m`. Supports unit and multi-field payload variants, qualified (`Shape.Circle(r)`, `Option(Of T).Some(v)`) and unqualified (`Circle(r)`, `Point`) construction, zero-init defaulting to tag `0`, `Operator` overloading, `Async`/`Await` return values, and exhaustive destructuring `Match ... With` with scoped payload bindings, `_` wildcards, and `When` guards.
- **Operator Overloading over `Structure` & `Union`**: `[Public | Private] Operator <op>(params) As RetType ... End Operator` supporting binary (`+`, `-`, `*`, `/`, `Mod`, `&`, `=`, `<>`, `<`, `>`, `<=`, `>=`, `And`, `Or`, `Xor`, `Shl`, `Shr`) and unary (`-`, `Not`) overloads where at least one parameter is a `Structure` or `Union` (including mixed scalar overloads in either order, contextual numeric literal matching such as `v * 2.0`, chained expressions, and rvalue `.field` access).
- **Structured Concurrency (`Async` / `Await` / `Task`)**:
  - `Async Function` / `Async Sub` returning first-class `Task(T)` / `Task` handles (usable in arrays, struct fields, and helper parameters) and `Await` expressions/statements.
  - Backed by deterministic zero-GC typed frames with true OS parallelism via `pthread_create`/`pthread_join` on Linux (x86-64, arm64), macOS (arm64), and Windows (x86-64 via MSYS2 winpthreads), auto-linking `-lpthread` only when used, and synchronous deferred thunks (zero `pthread` symbols) on freestanding bare-metal `arm-m`.
- **Functions, Parameters & Typed Function Pointers (`FuncPtr` / `SubPtr`)**: `Function` / `Sub`, forward registration, pass-by-value by default (redundant `ByVal` keyword removed) and `ByRef` parameters, explicit call-site `ByRef` (`foo(ByRef x)`), ABI-aligned struct return values, and first-class typed function pointers (`FuncPtr(params) As Ret` / `SubPtr(params)` with named, unnamed, grouped, `ByRef`, array/slice, struct, union, and nested `FuncPtr` parameters). `AddressOf(fn)` produces a strongly-typed `FuncPtr`/`SubPtr` (safely widening to `Pointer` for legacy C FFI while rejecting implicit `Pointer -> FuncPtr` and `AddressOf(Async)`), supports `Static` constant initialization, `IsNull`/`=`/`<>`/`0` null checks, indirect calls through variables, struct fields, `With` blocks, arrays/slices, generic inference (`Apply(x, AddressOf(fn))`), and `Task(FuncPtr(...))`, plus automatic VerBose-ABI C struct wrappers (`@__vb_fp_wrap_*`) when taking `AddressOf` of `Declare` C functions with ByVal structs across all targets.
- **Structs & Enums**: `Structure` (recursive ABI-aligned sizing, nested structs, deep `.` field access and assignment through `ByRef`), `With <lvalue> ... End With` zero-copy `.field` read/write blocks, `With ( field = expr, ... )` named initializers, positional struct constructors, and `Enum` (lowered to `i32`) supporting both qualified `EnumName.Member` and unqualified `Member` fallback (with local shadowing and compile-time ambiguity errors).
- **Authentic VB `()` Arrays**: Fixed arrays `Dim a(N) As T`, unsized slices `a() As T`, brace-free parenthesized array literals `()`, `(42)`, `(1, 2, 3)` (including inferred length `Dim b() As Integer = (1, 2, 3, 4)`), `a(i)` indexing, `Pointer` byte indexing, value/`ByRef` array parameters, and `Len()`.
- **Static, Heap & Deterministic Arena Memory**: Module-level and function-local `Static` globals, `SizeOf(Type)`, `HeapAlloc` / `HeapRealloc` / `HeapAllocBytes` / `HeapFree`, and first-class deterministic `Arena` bump allocator (`ArenaCreate`, `ArenaFromBuffer`, `ArenaAlloc`, `ArenaAllocBytes`, `ArenaReset`, `ArenaMark`, `ArenaRewind`, `ArenaUsed`, `ArenaRemaining`, `ArenaCapacity`, `ArenaDestroy`, `IsNull`).
- **Low-Level Address, Raw Pointer & MMIO Primitives**:
  - `AddressOf(expr)`: raw `Pointer` address of local/global variables, struct fields, array elements, and functions (including `Static Pointer` constant initializers for C FFI callbacks such as `qsort`).
  - `PtrRead(addr, Type)`, `PtrWrite(addr, Type, val)`, and `PtrAdd(addr, byteOffset)`: zero-overhead non-volatile typed pointer reads/writes (scalars and aggregate structs) and byte-level pointer arithmetic.
  - `Volatile Dim` and `[Public|Private] Volatile Static`: unoptimized, non-reordered LLVM volatile loads and stores propagating through struct fields and array elements.
  - Contextual `At <int-lit>` on `Static` globals (e.g. `Volatile Static GPIOA_ODR As Integer At 0x40020014`): binds variables directly to hardware MMIO addresses via `inttoptr` with no global storage.
  - `VolatileLoad(addr, Type)` and `VolatileStore(addr, Type, val)` for raw volatile typed pointer operations.
  - Hardware LLVM Atomics (`AtomicLoad`, `AtomicStore`, `AtomicAdd`, `AtomicSub`, `AtomicExchange`, `AtomicCas`, `AtomicFence`) emitting `seq_cst` LLVM atomic operations across all targets including bare-metal `arm-m`.
- **Modules & Encapsulation**: `Include "path.vb"`, `-I` search directories (plus `.` fallback), cross-platform `/` & `\` path and Windows `<drive>:` prefix normalization (`.`/`..`), circular-include detection, diamond include-once deduplication, `Public` / `Private` / `Default` visibility, and module-scoped `Private` isolation.
- **Native C Interop (FFI)**: `Declare Function` / `Sub`, variadic `...` with C default argument promotions (`Single→Double`, `Boolean/Byte/Short→i32`), `ByRef` out-pointers, target-native ByVal struct ABI lowering across SysV x86-64, AAPCS64, Microsoft x64, and ARM AAPCS (`Color`, `Vector2`, `Vector3`, `Rectangle`, `Camera3D`, `>16B` structs), UTF-8 & C-style string escapes (`\n`, `\r`, `\t`, `\"`, `\\`, `\0`), plus working 2D/3D Raylib 5.x demos (`bouncing_ball.vb`, `camera3d_demo.vb`, `README.md`) in [`tests/raylib/`](tests/raylib/) and dedicated [`tests/test_raylib.vb`](tests/test_raylib.vb) suite.
- **Standard Library (`std/`)**: Core pure-VerBose standard library designed for zero-GC, Arena-backed systems and embedded programming:
  - `std/strings.vb`: `StrLen`, `StrCmp`, `StrEq`, `StrStartsWith`, `StrEndsWith`, `StrIndexOf`, `StrFind`, `StrCopy`, `StrSubstr`, `StrConcat`/`StrConcat3`/`StrConcat4`, `StrJoin`, `StrRepeat`, `StrTrim`, `StrToUpper`, `StrToLower`, `StrToInt`, `IntToStr`, `LongToStr`, `HexToStr`, `DoubleToStr`, `BoolToStr`, Arena-backed zero-libc `{}` template formatting (`StrFmt1`/`2`/`3`/`Args`), zero-copy `StrView` (`StrViewFrom`, `StrViewEq`), and `StrBuilder` (`SbNew`, `SbReset`, `SbAppend`, `SbAppendSlice`, `SbAppendLine`, `SbAppendChar`, `SbAppendInt`, `SbAppendLong`, `SbAppendBool`, `SbAppendHex`, `SbAppendDouble`, `SbFinish`).
  - `std/sync.vb`: Pure-VerBose zero-GC synchronization primitives — bare-metal-safe `AtomicInt`, `AtomicLong`, `SpinLock`, `RwSpinLock`, `Once` (`SubPtr()`), `WaitGroup`, and reusable `SpinBarrier` built on LLVM `Atomic*` builtins, plus hosted POSIX/winpthreads `Mutex` and `CondVar` (auto-linking `-lpthread`).
  - `std/math.vb`: 100% pure VerBose math routines with zero `-lm` / libc math dependency: constants (`MATH_PI`, `MATH_TAU`, `MATH_E`, `MATH_HALF_PI`, `MATH_EPS`), integer utilities (`MathAbsI`, `MathMinI`, `MathMaxI`, `MathClampI`, `MathSignI`, `MathGcd`, `MathLcm`, `MathPowI`, `MathIsqrt`), 64-bit long utilities (`MathAbsL`, `MathMinL`, `MathMaxL`, `MathClampL`), and double-precision routines (`MathAbsD`, `MathMinD`, `MathMaxD`, `MathClampD`, `MathFloor`, `MathCeil`, `MathRound`, `MathSqrt`, `MathSin`/`MathCos`/`MathTan`, `MathExp`, `MathLn`, `MathPow`, `MathLerp`, `MathNearlyEq`, `MathDegToRad`, `MathRadToDeg`).
  - `std/result.vb`: Zero-GC, zero-libc, bare-metal-safe tagged-union `Option(Of T)` (`OptNone`, `OptSome`, `OptIsSome`, `OptIsNone`, `OptUnwrap`, `OptUnwrapOr`) and `Result(Of T, E)` (`ResOk`, `ResErr`, `ResIsOk`, `ResIsErr`, `ResUnwrap`, `ResUnwrapOr`, `ResUnwrapErr`, `ResOkOpt`, `ResErrOpt`).
  - `std/collections.vb`: Arena-backed generic `Vec(Of T)` and `Ring(Of T)` plus concrete `IntVec`, `PtrVec`, `IntRing` (fixed-capacity FIFO ring buffer), and `IntMap` (open-addressing linear-probing integer key-value hash map).
  - `std/io.vb`: Arena-backed file and console I/O: `IoReadFile`, `IoWriteFile`, `IoWriteText`, `IoAppendText`, `IoFileExists`, `IoFileSize`, `IoRemoveFile`, `IoPrint`, `IoPrintLn`, and `IoReadLine`.
  - `std/json.vb`: Strict RFC 8259 Arena-backed JSON DOM parser (`JsonParse`, `JsonParseWithCap`, `JsonGet`/`JsonAt`/`JsonFirst`/`JsonNext`, `JsonAsBool`/`Int`/`Long`/`Double`/`String`, `JsonDocNew`, `JsonNew*`, `JsonArrayPush`, `JsonObjectSet`, `JsonStringify`) and streaming `JsonWriter` (`JwNew`, `JwBeginObj`/`JwEndObj`, `JwBeginArr`/`JwEndArr`, `JwKey`, `JwField*`, `JwFinish`) with full `\uXXXX` + UTF-16 surrogate pair decoding, exact 64-bit integer parsing, nesting depth guard (64), and zero libc / bare-metal `arm-m` compatibility.
  - `std/span.vb`: Explicit length-carried, bounds-checked generic `Span(Of T)` (`SpanFrom`, `SpanInBounds`, `SpanGet`, `SpanSet`, `SpanAt`, `SpanSub`) plus concrete `ByteSpan`, `IntSpan`, `LongSpan`, `SingleSpan`, and `PtrSpan` with zero libc / bare-metal compatibility.
- **Built-in Testing & Assertions (`Test` / `Assert`)**: First-class `Test "name" ... End Test` blocks and `Assert <cond> [, "message"]` statements with the native `./verbose test [file.vb | dir]` runner (harness synthesis, failure isolation, auto-discovery, and C/library linking). See **[TEST.md](TEST.md)** for full testing documentation and examples.

## Compiler, Tooling & CI

- **100% Self-Hosted Compiler (`src/`)**: 10-module compiler (`19,297 LOC`: `verbose.vb`, `constants.vb`, `token.vb`, `lexer.vb`, `ast.vb`, `printer.vb`, `parser.vb`, `generics.vb`, `type_analyzer.vb`, `codegen.vb`) backed by a single 64 MiB deterministic `Arena`. Monomorphizes parametric `(Of T, ...)` generics into concrete zero-overhead ASTs before type-checking and codegen, lowers inline zero-GC tagged `Union` types with exhaustive destructuring `Match ... With`, lowers lexical-scope LIFO `Defer` statements, typed `FuncPtr`/`SubPtr` indirect calls with full C ABI parity, and LLVM hardware `Atomic*` primitives, emits full LLVM DWARF debug metadata (`-g`/`--debug`) with `.vb` filenames & line numbers, hoists all `alloca`s to LLVM `entry:` blocks (constant O(1) loop stack + full `mem2reg` register promotion), enforces hard compile-time stack-frame limits (`--max-stack`: `64 KB` hosted / `4 KB` `arm-m`, never silently spilling `Dim` to `malloc`), rejects out-of-bounds constant fixed-array indices at compile time with zero runtime cost, supports explicit opt-in `--bounds-check` runtime checks (off by default), dogfoods `Match ... With`, `For ... Do`, `With ... End With`, and unqualified enum members, compiles itself to a byte-for-byte Stage 3 self-hosting fixpoint (with automatic `BOOTSTRAP_CHAIN` cold-bootstrap fallback from older releases), and passes **37/37** pure-VerBose test suites (**226** `Test` blocks + **6/6** bootstrap tests) via `./verbose test` with zero OCaml or Python dependencies. The archival OCaml Stage 0 bootstrap compiler is preserved on the `stage0` git branch.
- **Cross-Compilation & Target Triples**:
  - Target presets via `--target <name>` / `--target=<name>` with automatic host target detection (overrideable via `VERBOSE_TARGET`): `linux-x86_64`, `linux-arm64`, `macos-arm64` (Apple Silicon), `windows-x86_64` (MinGW-w64/UCRT), and `arm-m` (bare-metal 32-bit Cortex-M / Thumbv7EM).
  - Target-specific LLVM `target datalayout`, `target triple`, and native C ABI lowering (SysV x86-64, AAPCS64, Microsoft x64, ARM AAPCS), eliminating `clang -Woverride-module` warnings.
  - Parameterized pointer sizes (4 bytes on `arm-m`, 8 bytes on 64-bit targets) and alignment rules.
  - Freestanding mode on `arm-m` (suppresses unused host libc imports).
  - Direct object file emission via `-c` / `--emit-obj` using `clang -O2 -c`.
- **Semantic Type Analyzer & Inspection**: Automatic semantic type checking (`--ta` verbose output, `--no-ta` opt-out), AST pretty-printer (`--ast`), and LLVM IR inspection (`--ir`).
- **Direct Compile-and-Run CLI & Built-in Test Runner**: `./verbose file.vb` type-checks, emits LLVM IR, compiles with `clang -O2`, and executes directly by default; `./verbose test [file.vb | dir]` (or `--test`) builds and runs native `Test`/`Assert` suites with full flag support (`--target`, `-c`, `--emit-only`, `--no-run`, `-o`, `-I`, `-l`, `-L`, `-W`, extra `.c/.o/.a` inputs, `--help`, `--version`).
- **Packaging & CI**: `make install` / `uninstall` / `dist` packaging plus lightweight GitHub Actions CI (`.github/workflows/ci.yml` — `clang` + `curl` only) and automated multi-platform GitHub Releases for Linux x86-64, Linux arm64, macOS arm64, and Windows x86-64 (`.github/workflows/release.yml`).
