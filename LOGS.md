## Ecosystem Extensions (Separate Repositories)

- [x] **Raylib Wrapper (`thetrung/verbose-raylib`)**: Modular idiomatic VerBose-Lang + C ABI wrapper for Raylib 5.x/6.x (`raylib_types.vb`, `raylib_ffi.vb`, `raylib_colors.vb`, `raylib_math.vb`, `raylib_gfx.vb`, `raylib.vb`), Raylib 5.x/6.x compatibility shim (`csrc/verbose_raylib_shim.c`), headless mock backend (`csrc/headless_mock.c`), `verbose.toml` package manifest, `4/4` ABI `sizeof()` & math tests verified against both headless mock and system Raylib 6.2, and 3 graphical demos (`01_particle_arena.vb`, `02_solar_system_3d.vb`, `03_arcade_breakout.vb`).
- [x] **Neovim Plugin (`thetrung/verbose.nvim`)**: Bundled Tree-sitter grammar (`tree-sitter-verbose/` with pre-generated `parser.c` + `highlights`/`locals`/`folds`/`indents` queries, 100% parse success on real compiler & Raylib code), Vim syntax fallback, zero-dependency in-process LSP (`verbose_ls`) with mtime-invalidated recursive `Include`-graph caching (nested struct `.field` chains, nested `With` blocks & inline `Type With (...)` initializers, lexical block scoping & `For` loop counters, `Task(T)`/`Await` unwrapping, `Enum.`, `Include "..."` completion, cross-file & nested-field `gd`/hover, document symbols, signature help, and `verbose --emit-only` diagnostics; `6/6` headless tests), and `:VerboseInstall` compiler installer fetching the latest GitHub Release (`v0.6.0`).
- [x] **Serverless Package Manager (`thetrung/verbose-pkg` / `vpm`)**: Cargo-inspired package manager written natively in VerBose-Lang (`vpm init/add/install/build/run/test/pack/list/clean`), resolving git repos, local paths, and portable source/prebuilt-binary `.vpkg.tar.gz` bundles, compiling/linking C shims into `.vpkg/lib/lib<dep>.a`, staging `.vpkg/include/<dep>/`, and verified end-to-end consuming both `verbose-raylib` and `verbose-tui`.
- [x] **TUI Framework (`thetrung/verbose-tui`)**: Ratatui-inspired zero-GC double-buffered TUI library backed by an `Arena` cell grid and tiny zero-ncurses POSIX `termios`/`ioctl`/`poll` C backend (`csrc/tui_term.c`), featuring diffed 24-bit TrueColor ANSI rendering, layout splits, Unicode widgets (`Block`, `Paragraph`, `Gauge`, `Sparkline`, `List`, `Tabs`, `StatusBar`), interactive multi-tab dashboard demo (`01_dashboard.vb`), `verbose.toml` manifest, and `4/4` automated tests.
- [x] **OpenSKP Wrapper (`thetrung/verbose-openSKP`)**: VerBose-Lang + C ABI wrapper around vendored MIT OpenSKP (`csrc/verbose_openskp.h/.cpp` + `src/openskp*.vb` + `miniz`), providing flat RAM access to SketchUp `.skp` meshes, instanced transforms, materials, layers, and scenes/pages (including SketchUp <14 `CImage` fix) with `3/3` automated tests.
- [x] **Webtoon `.skp` Renderer (`thetrung/verbose-viewSKP`)**: ZBrush-style multithreaded CPU Pixol G-Buffer + Toon/Ink Webtoon `.skp` studio written in VerBose-Lang `v0.7.0` using `verbose-openSKP` + `verbose-raylib`, featuring Hi-Z/Early-Z/band/LOD CPU rasterization, 2.5D instant screen-space relighting, 4 toon styles, 5 passes, 4-pass PNG export, live drag-and-drop/`Ctrl+O` model loading, live RAM usage HUD bar, and headless `--shot` CLI mode.

## Completed Tasks (`v0.7.3`)

- [x] **Strict Compile-Time Stack-Frame Limit Enforcement (`--max-stack`)**: Added exact target-aware type sizing (`TaTypeAlign` / `TaTypeSize` in 64-bit `Long`) and per-function/operator/test stack frame accounting in `src/type_analyzer.vb` (`TaSetTarget`, `TaSetMaxStack`, `TaAccountStackLocal`, `TaCheckFrameBudget`), enforcing hard compile-time errors (no silent `malloc` auto-spill!) when any `Dim` local or cumulative stack frame exceeds **`64 KB`** on hosted 64-bit targets or **`4 KB`** on bare-metal `arm-m` (nudging explicitly to `HeapAlloc`, `ArenaAlloc`, or `Static`, with explicit `--max-stack <bytes>` CLI override). Upgraded `tests/harness.vb` `FileHas` buffer from stack `Dim` to `Static`, added `tests/test_stack_limit.vb` (5/5 passing — **28/28** suites, **191/191** `Test` blocks, Stage 3 byte-for-byte fixpoint verified, refreshed `verbose.ll`, and updated Arch `PKGBUILD`/`.SRCINFO`).

## Completed Tasks (`v0.7.2`)

## Completed Milestones

- [x] **Multi-Platform Native Releases (`v0.5.1`)**: Added `linux-arm64` and `windows-x86_64` targets with host auto-detection (`VERBOSE_TARGET`), target-native C ABI struct lowering (SysV x86-64, AAPCS64, Microsoft x64, ARM AAPCS), C variadic default argument promotions (`Single→Double`, `Boolean/Byte/Short→i32`), Windows `\`/`<drive>:` `Include` path handling, dedicated `tests/test_raylib.vb` suite (19/19 suites, 151 `Test` blocks), and automated 5-job GitHub Releases publishing native binaries for Linux x86-64, Linux arm64, macOS arm64, and Windows x86-64 (`SHA256SUMS.txt`).

- [x] **Built-in `Test` / `Assert` & Zero-Python Testing**: Added first-class `Test "name" ... End Test` blocks, `Assert cond [, "msg"]` statements, and `./verbose test [file.vb | dir]` CLI runner; consolidated `examples/` into `tests/`, replaced all Python test runners with pure-VerBose suites, and removed `python3` from CI/Release workflows.
- [x] **Brace-Free Array Syntax, Stage 0 Archival & Repo Cleanup**: Replaced `{..}` array literals with `(..)` across Stage 0 and self-hosted compilers, archived `stage0/` onto the `stage0` git branch and removed it from `main`, and extracted `FEATURES.md`.
- [x] **Tooling & CI**: Added `make install`/`uninstall`/`dist` packaging and lightweight GitHub Actions CI + automated Linux x86-64 binary release workflows (`.github/workflows/ci.yml`, `.github/workflows/release.yml`).
- [x] **Self-Hosted Semantic Type Checker & CLI**: Ported semantic Type Analyzer (`src/type_analyzer.vb`, `--ta`/`--no-ta`), AST printer (`src/printer.vb`, `--ast`), IR printer (`--ir`), and full CLI driver (`src/verbose.vb`) with direct compile-and-execute by default.

- [x] **Cross-Compilation & Target Triples**: Emitted explicit LLVM target triples and data layouts for Linux x86-64, Linux arm64, macOS arm64, Windows x86-64, and bare-metal 32-bit ARM-M (Thumbv7EM), zero clang `-Woverride-module` warnings, added `-c`/`--emit-obj`, and added `Volatile` variables, fixed-address `At <addr>` MMIO registers, and `VolatileLoad`/`VolatileStore` primitives.
- [x] **Language Extensions**: Added structured concurrency (`Async Function`/`Sub`, `Task(T)`/`Task`, `Await` — `pthread` parallelism on Linux/macOS/Windows MSYS2 and zero-dependency deferred thunks on freestanding `arm-m`) and low-level memory/control primitives (`AddressOf`, `PtrRead`, `PtrWrite`, `PtrAdd`, `Label`, `GoTo`).
