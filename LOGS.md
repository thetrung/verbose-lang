- [x] **Serverless Package Manager (`thetrung/verbose-pkg` / `vpm v0.2.0`)**: Cargo-inspired multithreaded package manager written natively in VerBose-Lang (`vpm init/add/install/build/run/test/pack/list/clean`), using `Async`/`Await` for parallel dependency installation, C compilation, and test execution, `vpm run` argument forwarding, git/path/`.vpkg.tar.gz` bundles, `.vpkg/lib/lib<dep>.a` & `.vpkg/include/<dep>/` staging, and verified end-to-end across `verbose-raylib`, `verbose-tui`, `verbose-openSKP`, and `verbose-viewSKP`.
- [x] **TUI Framework (`thetrung/verbose-tui`)**: **100% pure VerBose-Lang** Ratatui-inspired zero-GC double-buffered TUI library backed by an `Arena` cell grid and direct native POSIX `termios`/`ioctl`/`poll` FFI (`src/tui_term.vb`, zero `ncurses`, zero custom C shims!), featuring diffed 24-bit TrueColor ANSI rendering, layout splits, Unicode widgets (`Block`, `Paragraph`, `Gauge`, `Sparkline`, `List`, `Tabs`, `StatusBar`), interactive multi-tab dashboard demo (`01_dashboard.vb`), `verbose.toml` manifest, and `4/4` automated tests.
- [x] **OpenSKP Wrapper (`thetrung/verbose-openSKP`)**: VerBose-Lang + C ABI wrapper around vendored MIT OpenSKP (`csrc/verbose_openskp.h/.cpp` + `src/openskp*.vb` + `miniz`), providing flat RAM access to SketchUp `.skp` meshes, instanced transforms, materials, layers, and scenes/pages (including SketchUp <14 `CImage` fix, zero-retention scene flattening with interned instance names cutting steady RAM 7.9× from `2.84 GB → 361 MB` on 740k-instance models, and non-regex generic-name parsing) with `3/3` automated tests.
- [x] **Webtoon, PBR & RayTrace `.skp` Studio (`thetrung/verbose-viewSKP`)**: **100% pure VerBose-Lang** ZBrush-style multithreaded CPU Pixol G-Buffer + 2.5D Toon/Ink + Cook-Torrance GGX PBR + 2-Level CPU BVH RayTracing `.skp` studio using `verbose-openSKP` + `verbose-raylib` via `vpm`, featuring 60+ FPS pre-ranked top-2400 GPU per-object BBox / CPU monochrome line preview (`[F5]`), camera-distance adaptive triangle/crease LOD (`[F4]` Auto/High/Fast) with O(N log N) iterative quicksort + cached per-frame screen bounds (cutting 740k-instance load time `18.2s → 3.6s`, visibility sort `2,694ms → 14.7ms`, and CPU preview `2,737ms → 1.3ms`), adjustable 2.5D Depth-of-Field camera focus blur (`[F6]`), progressive partial rendering (`[F7]`), Sutherland-Hodgman near-plane clipping, FPS view-aligned navigation, clickable/draggable/deletable 3D lights, scene lock (`[F8]`), tabbed `Objects`/`Layers` visibility outliner, 2.5D Edge-AA/FXAA, live RAM usage HUD, and headless `--shot` CLI mode.
- [x] **SQLite3 Wrapper (`thetrung/verbose-sqlite3`)**: **100% pure VerBose-Lang** zero-C-shim FFI wrapper around system `libsqlite3` (`src/sqlite3_ffi.vb`, `src/sqlite3.vb`) with 35 native `Declare Function` bindings, `SQLITE_TRANSIENT` 64-bit pointer safety (`Pointer(Long(-1))`), `sqlite3_free` error cleanup, Arena-backed `SqlColTextArena`/`SqlColBlobArena` so results outlive `SqlStep`/`SqlFinalize`, `SqlEnableWal` + `SqlSetBusyTimeout`, `verbose.toml` vpm manifest, `examples/01_kv_store.vb`, and `7/7` automated tests verified under both default and `--bounds-check` modes.

## Completed Tasks (`v0.8.0` + post-release)

- [x] **Standard Library JSON Module (`std/json.vb`)**: Added a 100% pure-VerBose, zero-GC, zero-libc, bare-metal-safe RFC 8259 JSON module (`1,552 LOC`) providing both a flat Arena-backed node-pool DOM (`JsonDoc`, `JsonNode`, `JsonParse`, `JsonGet`/`JsonAt`/`JsonFirst`/`JsonNext`, `JsonAs*`, `JsonNew*`, `JsonStringify`) and a streaming `JsonWriter` (`JwNew`, `JwBeginObj`/`JwBeginArr`, `JwField*`, `JwFinish`) with full `\uXXXX` + UTF-16 surrogate pair decoding, exact 64-bit integer parsing (`INT64_MIN`..`INT64_MAX`) with overflow promotion to `Double`, nesting depth guard (64), and strict syntax error rejection. Added `tests/test_std_json.vb` (6/6 PASS under default & `--bounds-check`, freestanding `--target arm-m -c` verified; **31/31** suites, **206/206** `Test` blocks).
- [x] **Milestone 1 — Generics (Zero-Overhead Monomorphized Parametric `Structure`, `Function`, `Sub`, `Operator`)**:
  - **VB-style brace-free generic syntax (`(Of T, ...)`)**: Added `TkOf` (`Of`) in `src/token.vb`/`src/lexer.vb`, `NdTypeRef` plus `genStart`/`genCount`/`tyArgStart`/`tyArgCount` AST fields in `src/ast.vb`, full generic parameter & argument parsing across `Structure`, `Function`/`Sub` (including `Async`), `Operator`, type annotations, `Task(Box(Of T))`, `SizeOf`, `ArenaAlloc`, `HeapAlloc`, `HeapRealloc`, `PtrRead`/`PtrWrite`, `VolatileLoad`/`VolatileStore`, `With (...)`, positional constructors, calls, and `AddressOf(Fn(Of T))` in `src/parser.vb`, plus `--ast` pretty-printing in `src/printer.vb`.
  - **Dedicated Monomorphization Pass (`src/generics.vb`)**: Added deterministic pre-TA AST monomorphization with collision-free name mangling (`Base__Of_<A1>_And_<A2>_End`), specialization caching, recursion & infinite-instantiation depth guards (`32` depth / `512` struct / `1024` func caps), arena-backed kid scratch stack (zero recursive frame bloat), `T(x)` primitive cast / struct constructor rewriting, full structural call-site type argument inference (including nested patterns like `Box(Of Pair(Of A, B))`, `With (...)` / positional struct inference, and on-demand generic `Operator` overloads), and cross-module `Private` type-argument support (`ta_altModId` in `src/type_analyzer.vb`).
  - **Generic Standard Library Containers & Views**: Added `Span(Of T)` (`SpanFrom`, `SpanInBounds`, `SpanGet`, `SpanSet`, `SpanAt`, `SpanSub`) in `std/span.vb` and `Vec(Of T)` / `Ring(Of T)` (`VecNew`/`VecPush`/`VecPop`/`VecGet`/`VecSet`/`VecClear`, `RingNew`/`RingPush`/`RingPop`/`RingLen`/`RingIsEmpty`/`RingIsFull`) in `std/collections.vb` while keeping all existing concrete types backwards-compatible.
  - Added `tests/test_generics.vb` (6/6 passing — **30/30** suites, **200/200** `Test` blocks, Stage 3 byte-for-byte fixpoint verified, freestanding `arm-m` generic cross-compilation verified, refreshed `verbose.ll`, and updated Arch `PKGBUILD`/`.SRCINFO`).

## Completed Tasks (`v0.7.4`)

  - **Zero-cost compile-time constant OOB errors**: Added `TaTryEvalConstInt` in `src/type_analyzer.vb` to reject out-of-bounds constant integer indices (including negative indices & constant `+`/`-`/`*` expressions) on fixed-size arrays at compile time with zero runtime overhead.
